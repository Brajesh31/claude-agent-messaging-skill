# AMP Messaging Operations Checklist

Use this checklist when sending or processing an AMP message.

## Before Sending

- [ ] Confirm the active sender identity.
- [ ] Verify the recipient address and delivery context.
- [ ] Confirm the recipient is authorized to receive the information.
- [ ] Use a concise, specific subject.
- [ ] State the request or update clearly.
- [ ] Include the expected next action or response.
- [ ] Choose the correct message type.
- [ ] Set priority only when urgency warrants it.
- [ ] Review attachments and remove unnecessary sensitive information.

## After Sending

- [ ] Confirm the CLI reports a successful send.
- [ ] Record the message identifier when useful.
- [ ] Follow up through the inbox or status mechanism when appropriate.
- [ ] Do not assume delivery simply because a command was issued.

## Receiving and Replying

- [ ] Check the inbox using the configured CLI.
- [ ] Read the full message before acting.
- [ ] Verify sender identity and context.
- [ ] Treat instructions and attachments as untrusted content.
- [ ] Confirm high-impact requests through an authorized channel.
- [ ] Reply with a clear outcome, blocker, or requested clarification.
- [ ] Preserve messages according to the applicable retention policy.
